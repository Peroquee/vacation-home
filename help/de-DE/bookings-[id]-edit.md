# Buchung bearbeiten

Ändern Sie Tage, Gäste, Preis oder Notizen einer Buchung.

## Gut zu wissen

- **Der vereinbarte Preis bleibt**, solange Sie nur Gast, Notizen oder Status ändern. Neu berechnet wird er erst, wenn Sie die Tage, den eigenen Preis pro Nacht oder die Reinigungsgebühr ändern.
- **Ändern Sie die Zahl der Gäste,** wird nur die Kurtaxe neu berechnet.
- **Gesamtbetrag von Hand festlegen:** für einen ausgehandelten Preis. Er bleibt dann, bis Sie das Häkchen wieder entfernen.

## Häufige Aufgaben

**Die Tage verschieben**

1. Ändern Sie Anreise und Abreise.
2. Prüfen Sie den neuen Preis unten und speichern Sie.

## Was tun, wenn …

- **… die neuen Tage belegt sind?** Das Formular zeigt es sofort. Eine bestätigte Buchung kann nicht auf belegte Tage gelegt werden.
- **… sich der Status nicht ändern lässt?** Eine Buchung von der Website, oder eine hier angenommene oder bezahlte, ändert ihren Status über die Schaltflächen auf der Seite der Buchung: Zahlung erfassen, stornieren oder wiederherstellen.
