# Neue Buchung

Für eine Buchung, die nicht über Ihre Website kommt: ein Anruf, eine E-Mail, Stammgäste.

## So geht's

1. Wählen Sie die **Unterkunft** und den **Gast** (oder legen Sie einen neuen an).
2. Geben Sie **Anreise** und **Abreise** ein. Das Formular sagt sofort, ob die Tage frei sind.
3. Geben Sie die Gäste an (Erwachsene und, wenn gefragt, Kinder nach Alter).
4. Prüfen Sie den Preis unten: Er wird aus Ihren Saisonpreisen, Rabatten und der Reinigungsgebühr berechnet.
5. Wählen Sie den **Status** und speichern Sie mit **Buchung anlegen**.

## Gut zu wissen

- **Eigener Preis pro Nacht:** leer lassen, dann gelten Ihre Saisonpreise. Ein Preis hier gilt für jede Nacht gleich.
- **Gesamtbetrag von Hand festlegen:** für einen ausgehandelten Gesamtpreis.
- **Warnungen zu Buchungsregeln** (z. B. Mindestaufenthalt) sind nur Hinweise: Sie dürfen trotzdem buchen.
