# Posten importieren

Übernehmen Sie viele Posten auf einmal aus einer CSV-Datei, z. B. einem Kontoauszug.

## So geht's

1. Laden Sie die Datei hoch.
2. Ordnen Sie die Spalten zu: Datum, Betrag, Beschreibung.
3. Prüfen Sie die Vorschau. Doppelte Posten erkennt die App und lässt sie weg.
4. Wählen Sie Kategorie und Unterkunft und importieren Sie.

## Was tun, wenn …

- **… die Beträge falsch aussehen?** Prüfen Sie, ob die Datei Komma oder Punkt als Dezimalzeichen nutzt, und wählen Sie das passende Format.
